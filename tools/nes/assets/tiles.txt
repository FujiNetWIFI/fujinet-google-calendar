# tiles.txt -- the client's icons and sprite shapes. tools/nes/mkchr.py.
#
# A block is a header and eight rows of eight pixels:
#
#   = bg $NN            a background tile: '.' is colour 0 (the ground),
#                       '1' '2' '3' the palette's other three
#   = spr $NN           a sprite tile, the same way ('.' transparent)
#   = spr $NN slots     a sprite shape drawn with '#': mkchr writes it three
#                       times, at $NN+1, +2 and +3, in colour 1, 2 and 3 --
#                       so any of the twelve sprite slots (src/nes/gen_pal.s)
#                       is a (palette, tile) pair
#
# The background palettes (tools/nes/palette.py): BP0 is ground, text, line,
# accent; so '1' is text-coloured, '2' line grey, '3' Google blue.
